02 · IA que trabaja de noche

Runner y agentes

Cada mañana a las 6:00 un ejecutor coge las tareas aprobadas, trabaja en una rama aislada de cada repositorio y deja un pull request para revisar. Tiene un tope de gasto por tarea. Si algo no cuadra, no adivina: devuelve la tarea con el motivo.
